01 — 产品功能

三件事，前两件最重要。

你可能也遇到过：聊到一半额度用完了；换了个账号，旧对话就找不回来了。 我们把这两件事分别解决掉——而且不让聊天绕远路。

  1. 01

    一键迁移 DeepSeek 原有会话

    把你在 DeepSeek 网页版的历史对话整批搬进来：在导出页登录一次，服务器代跑导出， 手机端输入导入码就能落到本地。以前那些"说不完的话"，接得上。

    核心 · 迁移
  2. 02

    DeepSeek API 直连

    聊天请求从手机直接发往 api.deepseek.com，不经过我们的服务器： 没有中转、没有排队、没有第二个副本。模型、深度思考、联网搜索和官方一致。

    核心 · 直连
  3. 03

    也支持用你自己的 Key

    不想走我们的账号，就把自己的 DeepSeek API Key 填进来，费用在你自己的平台账户里结算， 我们不碰钱、也看不到 Key。

    可选 · BYOK

02 — 数据怎么走

聊天不经过我们，所以也留不下。

所有对话请求从手机直接发往 DeepSeek 服务器，我们这条链路里没有对话原文。 服务器只做三件事：发账号、发 Key、按天汇总 token 数算钱。

会话不过期

对话存在你自己的手机里，随时可导出成文件带走；平台那边清理了，你这边还在。

没有时段限额

不按"每天几点到几点"限制你；额度按量计，白天深夜都一个价。

备份可选

想让换手机不丢，可以在设置里开备份；不开就完全只在本机。

陪伴，是最长情的告白。
我们只是把它保存下来。

02 — 原则

我们相信的三件事。

长情

工具可以换，记录不该丢。我们把它当一份可以一直续写的文件，而不是一次性的聊天窗口。

诚实

今日、本周花了多少钱，明明白白写在账号里。单价跟 DeepSeek 平台一致，不玩积分和倍率。

克制

界面只留两个开关：深度思考、联网搜索。没有一堆让人猜的参数，也没有必须点的弹窗。

07 — 关于

Deekseep 这个名字。

DeepSeek 是模型的名字，Deekseep 是我们的名字——一个我们自己起的、和它并肩站着的名字。 底层全部直连 DeepSeek 官方 API，模型能力一点没变；我们多做了一件事：把对话留下来。

客户端基于 deepseek-ai/chat-demo 的接口协议，用 Kotlin + Jetpack Compose 重写。Deekseep 不是 DeepSeek 官方产品， 与深度求索公司没有隶属关系。
